# Goals

## Primary Goal

Build a HashMap from scratch in C to understand how hash tables work internally instead of relying on built-in implementations.

## Core Goals

- Implement key-value storage using C structures.
- Implement a hash function to convert keys into table indices.
- Handle hash collisions correctly.
- Support insertion, searching, and deletion.
- Implement dynamic resizing of the hash table.
- Manage memory manually using `malloc`, `calloc`, `realloc`, and `free`.
- Handle memory allocation failures safely.
- Maintain a reasonable load factor for performance.
- Measure and understand the time complexity of operations.

## Learning Goals

- Strengthen C programming.
- Improve pointer and dynamic memory management skills.
- Understand hashing and collision resolution.
- Understand how resizing affects performance.
- Practice designing a reusable C module.
- Build a foundation for [[MiniDB]], [[KVStore]], [[CodeAI Cache & Indexer]], and [[SearchEngine]].

## Final Goal

Create a reliable, reusable HashMap implementation that can later serve as a low-level component in other systems projects.
